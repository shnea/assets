# 브랜드 기준

기본 심볼은 특정 폰트의 S와 H를 겹친 뒤 두 글자의 공통 부분만 남긴 **SH 심볼**이다. 단순한 S로 설명하거나 H의 기원을 지우는 방향으로 재해석하지 않는다.

사용자가 선택한 방향은 `assets` 워드마크의 첫 번째 s 자리에 SH 심볼의 겹침과 잘림을 녹이는 조합이다. 원본 로고를 카드나 배지 위에 올려놓는 초기 방향은 사용자가 거절했다.

- 승인 참고 이미지: `design/brand/approved-wordmark-reference.png`
- 전체 콘셉트: `design/brand/identity-concept-v2.png`
- 화면에 쓰는 고해상도 워드마크: `design/brand/assets-wordmark-sh-v3.png`
- 원본 SH 심볼: `design/brand/shnea-symbol.png`

로고 이미지는 별도 객체로 사용한다. 원본 이미지나 승인된 형태를 임의로 덮어쓰지 않는다.
